# On-Chain Liquidity Landscape

本部分沿 AMM 的发展脉络展开：恒定乘积 AMM → 被动性的代价（IL/LVR）→ 集中流动性 → 缓解方案光谱 → 聚合器 → RFQ 与 intent → 预言机，最后做横向对比。每一站都是对上一站缺陷的回应，主线只有一条：**被动资本逐步出局，专业报价逐步接管**。

## 1. AMMs: x·y=k

传统 AMM（Uniswap v2 及其分叉，如 BSC 上的 PancakeSwap）用一条数学曲线代替人工报价：池内两种资产数量的乘积恒定（x·y=k），**价格 = 两堆资产的比例**，任何人存入等值双边资产即可成为被动 LP，按份额分享交易手续费（经典费率 0.3%）。

**用数字推一遍定价与滑点。** 池子：100 BNB × 60,000 USDT，k = 6,000,000，现价 = 60,000/100 = 600 USDT/BNB。taker 用 600 USDT 买 BNB：

1. USDT 入池：60,000 → 60,600；
2. 乘积守恒，BNB 必须变为 6,000,000 ÷ 60,600 = 99.0099；
3. taker 得到 100 − 99.0099 = 0.9901 BNB，**实际均价 606.06**——比牌价 600 贵约 1%，这 1% 即滑点；
4. 交易后新牌价 = 60,600/99.0099 ≈ 612——**swap 本身推动了价格**。

滑点没有被任何人"收走"，它是曲线的几何性质：买走的越多，比例对 taker 越不利，成交沿曲线滑动，均价必然差于起点瞬时价。好记的近似：

> **交易量占池子储备的比例 ≈ 吃到的滑点比例。** 池子大十倍，同样订单滑点小十倍——这就是"深度"在 AMM 中的数学形态。

**LP 的收益结构是一本双栏账。** 明账：手续费收入，永远为正，也是所有前端展示的 APY 来源。暗账：持仓价值变化——LP 存入的不是定期存款，而是一个**会自动向不利方向调仓的组合**（机制见 2.2）。真实收益 = 手续费 − 再平衡损耗，只看明账是 DeFi 中最经典的认知陷阱。

**该模型的深刻缺陷**：这条曲线就是 AMM 的报价单，但它是**死的**——形状由 k 定死，位置只被动地被交易推动，没有人根据市场行情主动挪它。用 Part I 的语言：传统 AMM 是一个**永不刷新报价、也永不撤单的做市商**，报价过期窗口无限大。它用这个致命缺点换来的，是完整的无许可可组合性：任何代币、任何人、无许可建池，任何合约可原子调用——这个交换是否划算，取决于资产类型（见 2.8）。

## 2. 被动投资代价: CEX-DEX 套利, IL, and LVR

**CEX-DEX 套利的完整链路。** CEX 价格毫秒级连续跳动，AMM 池价只在有人交易时变动——一潭静水对一条活水。设两边同为 600，Binance 一波买盘推到 606：

1. 链上池子毫无感知，仍停在 600；
2. 套利者在链上按约 600 开始买入 BNB，同时在 Binance 按 606 卖出；
3. 买到池价约等于 606、无利可图为止。

DEX 价格追上 CEX，靠的不是任何同步机制，就是套利者用真金白银搬齐的——而套利者赚走的每一分钱，都来自池子 LP 按旧价卖出的资产。这个套利者就是 Glosten-Milgrom 中"知情者"的链上肉身：他的信息优势不是内幕，仅仅是"看得到 CEX 价格 + 手速更快"。

**无常损失（Impermanent Loss, IL）**：以 HODL 为基准的 LP 损失。存入 1 BNB + 600 USDT（总值 1,200），BNB 涨到 1,200 后曲线自动再平衡，LP 份额变为约 0.707 BNB + 848.5 USDT ≈ 1,697，而 HODL = 1,800，IL ≈ 103（5.7%）。池子机制注定：**涨的资产被按一路偏低的旧价分批卖出，跌的资产被按偏高旧价接盘**——LP 永远在做与正确方向相反的交易，对手正是知情者。

**IL 的致命盲区**：价格回到原点时 IL 显示为零（"无常"由此得名），但涨和跌的两趟路上套利者各收割了一次——损失真实发生了，IL 把账藏掉了。

**LVR（Loss-Versus-Rebalancing）**：更严格的基准——一个与池子持仓完全同步、但**按 CEX 实时公允价成交**的影子组合。池子实际成交价与公允价之差的累积，就是 LVR。

**用数字算一次单事件 LVR。** 沿用 2.1 的池子，CEX 从 600 跳到 606，套利者把池价搬平：

- 池子变为约 99.50 BNB × 60,299 USDT，套利者买走 0.4963 BNB、支付 299.3 USDT（均价约 603，恰在新旧价之间——他沿曲线从 600 一路买上去）；
- 套利者在 CEX 按 606 卖出：收入 300.8，利润 ≈ **1.5 USDT**；
- 影子组合同样卖出 0.4963 BNB 但按 606 成交，收入 300.8；池子实收 299.3——**本次事件 LVR = 1.5 USDT**。

注意恒等式：**LP 的 LVR ≡ 套利者的利润**——同一笔钱的两个名字。这笔钱由全体 LP 按份额分摊，且藏得极深：池子代币数量看起来一切正常，损失只体现为"相对本该有的状态"的缺口。

LVR 的三个关键性质（与 IL 对比记忆）：

| | IL | LVR |
|---|---|---|
| 基准 | HODL | 随时按公允价再平衡的影子组合 |
| 价格回到原点 | 归零（藏账） | 只增不减（逐笔累积） |
| 决定因素 | 涨跌幅 | 波动率（≈ σ²/8 × 池值，与价格终点无关） |
| 含义 | 混合了持仓的市场风险 | 纯粹的逆向选择成本 |

**LP 的生死判决式**由此清晰：专业做市商在 CEX 对冲掉市场风险后，链上做市的净亏损恰好是 LVR，净收入是手续费——

> **手续费收入 > LVR 则活，反之则死。** 波动率翻倍，LVR 约变四倍；被动 LP 对两侧变量都没有方向盘，当 LP 本质上是买一张"交易量 vs 波动率"的彩票。

**出块速度与 gas 如何放大 LVR**：池价每个区块最多更新一次，出块间隔就是报价被冻结的最小时长——间隔越长，冻结期内 CEX 累积的偏移越大（约与时间平方根成正比），套利者可捕获的价差越肥。gas 则是"买一次新鲜度"的单价：gas 越贵，一切主动更新策略（挪 v3 区间、传曲线参数）越频率受限，全链报价集体变馊。这是"链的工程参数直接决定做市质量"的第一次显形。

**为什么 Uniswap 们没有因此转不起来**——市场实际在分层：稳定币对波动趋零、LVR 趋零，被动 LP 安然存活；散户流巨大的蓝筹对手续费可以盖过 LVR；流动性挖矿补贴填了很多池子的窟窿；相当比例的 LP 从未对照基准算过总账；而**长尾资产没有专业做市商愿意报价，被动 AMM 是唯一选项**——这是它不可替代的生态位。被 propAMM 革命的战场，集中在"波动大、量也大"的主流交易对上。

## 3. Uniswap v3

v2 的资本浪费：x·y=k 覆盖从 0 到无穷的所有价格，而现实中资产 99% 的时间在现价 ±20% 内波动——**池内绝大部分资本趴在永远不会被触及的价格段上睡觉**。

v3 的解法：LP 存入时指定价格区间（如 550–650），资本全部集中在该段。价格在区间内则全额参与成交、全额赚费；价格穿出区间则仓位自动变为单一资产并停止工作。**tick** 是价格轴上预刻的最小刻度（约 0.01% 步长），区间端点必须落在 tick 上——把连续价格离散化，合约才算得动。

资本效率的量级：只覆盖现价附近 ±8% 左右的区间，相同深度所需资本可比 v2 少约 20 倍；等价地，相同资本在现价附近提供的深度厚约 20 倍。v3 上线后主流对滑点大幅下降。

代价是 **LP 被迫变成半个做市商**：区间窄 = 火力集中 = 被再平衡收割也集中（IL 被同倍数放大）；价格移出区间必须手动挪仓，不管理就躺平吃灰。由此催生了主动管理 LP 仓位的整个行业。

**v3 在演化线上的位置**：它已把"被动"推到极限——一个不断随行情挪区间的 v3 LP，行为上已经很像在挂撤单，只是"报价"仍是固定形状的曲线，挪一次仓要发一笔昂贵交易。propAMM 只是把这个趋势走到终点：既然 LP 已不得不主动，干脆让专业做市商上传任意形状的曲线、毫秒级更新、不带散户资本玩。

## 4. 缓解措施的多种选择：征税、出售还是预防

LVR 是一笔确定要漏出去的钱，堵法归为三种思路，排成一条从打补丁到换地基的光谱：

**动态手续费——按毒性收税。** 套利者只在"价差收益 > 手续费"时出手，那就在波动大时（正是套利出没时）自动调高费率，把套利利润挤薄；平静时降费吸引散户。局限：费率对所有人一起调，挡套利的同时也挡了部分好客人；只是让漏水变慢，没堵住洞。

**拍卖优先权——堵不住就把"抢劫权"卖掉。** 每个区块"第一个吃掉过期报价"的机会横竖会被某个套利者抢走，与其让他白拿，不如公开拍卖这个位置、拍卖款返还 LP。套利者互相竞价，利润大头以竞拍款形式流回受害者口袋——LVR 没消失，但被回收了（学术设计如 am-AMM、MEV tax；广义上 Jito 的小费拍卖属同一家族）。这个思想的一般形式值得单独记住：**区块内的优先位置是稀缺资源，拍卖是它最不坏的分配机制**——相比拼手速（军备竞赛+垃圾交易）和拼关系（不透明），拍卖让资源流向估值最高者、把争抢的能量转化为可分配收入、且规则对新玩家开放。

**Oracle 定价——从机制上让过期报价不存在。** 前两招默认"报价会过期"，第三招掀桌：池子定价不再由池内资产比例决定，而是每次成交时读取预言机的实时价格。代表是 **Lifinity**（2022，Solana）：定价挂在 Pyth 上，taker 交易中原子打包"刷新价格指令 + swap"，保证按最新 oracle 价成交——用真实运营证明了链上池子可以基本免疫 LVR。

Lifinity 同时暴露了新问题：定价能力外包给了预言机，报价新鲜度和准确度的天花板就是预言机的天花板；且 oracle 给的是一个价，不是完整的买卖盘型（不同深度收多少 spread、库存偏了怎么歪报价）。专业做市商由此自然想到：预言机的价格本来就源于我们这类机构的数据，**与其绕道，不如直接把自己定价模型的输出上链**——这一步跨出去就是 propAMM（Part III）。

## 5. 聚合器：路由、中立性和模拟差距

聚合器（Jupiter、1inch、0x、KyberSwap、OKX DEX 等，均为独立第三方团队、多为多链部署）是链上订单流的比价路由层。它下面挂的不只是做市商，而是**所有异构的流动性源**：被动 AMM 池（背后是散户 LP）、propAMM（专业做市商）、RFQ 报价源（专业做市商）。

**路由决策三步：**

1. **拿到报价 / 模拟成交**：对链上源不发询价，直接读状态自己算（v2 读储备套公式，v3 读 tick 分布，propAMM 读当前曲线参数）；对链下 RFQ 源发真实询价、收回签名报价；
2. **比价**：解一个最优化问题——目标是用户最终到手最多，需扣除多路 gas、有效期风险、历史成交质量等隐性成本；
3. **拆单路由**：大单几乎从不走单一源（滑点 ≈ 交易量/池子储备），拆成多路加权后优于任何单一路径，编码成一笔交易原子执行。

**中立性问题。** 聚合器的守门人权力来自 1.6 的原理（入口即权力），而它的可信度取决于利益结构：

- **Jupiter（Solana）是纯裁判**：自己不运营池子，路由给谁都不心疼，商业利益与用户利益同向——新做市商冷启动只需一道门：向 Jupiter 证明报价好；
- **PancakeSwap（BSC）既当裁判又当最大运动员**：它是 BSC 最大交易入口，同时自己就是最大 AMM——把订单路由给报价更好的第三方，等于亲手分流自家池子的手续费与 CAKE 价值捕获。这不是作恶，是资产负债表决定立场。

**模拟-成交缝隙（simulation gap）。** 第 1 步的模拟发生在决策时刻，成交发生在上链时刻，两者之间隔着签名、广播、排序、出块的延迟。对被动 AMM 这不是大问题（曲线没人动）；对报价每几百毫秒变一次的 propAMM，**聚合器看到的价和 taker 结算的价之间出现了一个可被武器化的缺口**——Part III 的 Base 一节是这个缺口被系统性利用的实证。

**聚合器的囚徒困境。** 用户选聚合器看展示报价，几乎不核对最终结算价；而作恶报价源恰好让"展示价好看、结算价坑人"。于是：严格剔除作恶源的聚合器展示报价变差、用户流向纵容作恶的竞品——单方面做好人代价最大，理性玩家滑向集体做坏人（经典柠檬市场）。出路是让质量可见：公布各报价源的"报价 vs 结算"偏差数据、按结算质量而非展示报价路由，或在机制层面把报价与结算焊死（签名报价、intent 底线）。

## 6. RFQ and Intents: 通过签名确保执行确定性

**RFQ（request-for-quote）四步流程**，以"用 60,600 USDT 买 100 BNB"为例：

1. **询价（链下）**：taker/聚合器向做市商 API 发请求；
2. **签名报价（链下）**：做市商定价引擎回一张"电子支票"——以 100 BNB 换 60,600 USDT，只限地址 0xJoey 使用，有效期至 T+3s，编号 #8842（防重放），附签名；
3. **taker 上链**：把签名报价整体塞进自己的交易，发给结算合约；
4. **验签结算（链上原子执行）**：合约验证签名、有效期、调用者、编号，通过则按报价单原样划转——**成交价 = 报价单上的价，零滑点、零漂移**。

RFQ 的本质：**执行确定性来自密码学，而非排序**。成交价写死在签名里，交易被排在哪、前面有谁，统统无所谓——它根本不需要向任何人讨排序保证。价差能报窄的原因：做市商的敞口被对象/金额/价格/时限四个字段切成完全可预估的小方块（保险费薄），且能按询价者身份分拣客流（好客人报紧、机器人报宽或不报）。

代价与命门：**可组合性差**——签名报价是指名的私人信件，单一 taker、单次使用，其他合约无法引用、聚合器无法当公共池子模拟；**有效期两难**——期内做市商不可撤单（价格暴动也得按旧价兑现），期太短 taker 来不及上链。出块越快的链，这个两难越宽松。

**Intent 模式（UniswapX 等）把主客关系翻转**：用户不再签署执行路径，只签署结果约束——"我出 60,600 USDT，**至少**拿回 100 BNB，T 时刻前有效"。专业的 **filler**（做市商/套利团队）竞争接单：自己垫资、自己付 gas、自己决定从哪里凑货（自有库存、AMM、CEX 对冲），结算合约只验证用户签名的底线被满足。UniswapX 用荷兰拍组织竞争：要价随时间自动下降，哪个 filler 觉得有利可图就立刻出手，竞争把 filler 利润压薄、返还给用户。

Intent 的意义：报价-结算缝隙被合约焊死（交割不达标直接回滚），用户免 gas、免路由知识、免执行失败风险；代价是荷兰拍需要时间、filler 是有准入的专业玩家（竞争不足时 filler 联盟成为新的寻租者）、"谁能看到意图流"又成为新的订单流权力。RFQ 与 intent 是镜像：前者 taker 求 maker 签支票，后者 taker 自己签支票、makers 抢着兑——殊途同归，都属于"签名+底线取代信任执行环境"的一支。

## 7. Oracles: Push vs Pull

预言机把链下价格搬上链，两种模式的差异对报价类应用是决定性的：

- **Push（Chainlink、Binance Oracle）**：预言机按"偏离阈值 + 心跳时间"主动推送。更新频率低（分钟级常见），对做市场景太慢；
- **Pull（Pyth）**：链下持续产生签名价格流，应用方在需要时按需取用——**taker 把签名价格数据打包进自己的交易，合约验签后使用**，新鲜度可达 400ms 以内。

注意 pull 模式的形状："taker 自带签名数据上链、与业务逻辑原子执行"——这个机制骨架先被 Lifinity 借去做了 oracle 定价 AMM，后来又被签名报价类方案（预取式设计）沿用。另一个工程细节：EVM 的 block.timestamp 只有秒级精度，对毫秒级有效期的判定不够用——依赖有效期的报价类方案需要更高精度的时间源。

## 8. Comparative Summary

把本部分出场的所有模式放进同一个坐标系。三个核心维度：**报价新鲜度**（决定价差与 LVR）、**可组合性**（能否被聚合器/合约无摩擦调用）、**执行确定性来源**（凭什么保证"看到的价=成交的价"）。

| 模式 | 报价新鲜度 | 逆向选择暴露 | 可组合性 | 执行确定性来源 | 谁承担做市盈亏 |
|---|---|---|---|---|---|
| 恒定乘积 AMM (v2) | 极差（曲线只被交易推动） | 无限窗口，LVR 全额 | 极好（无许可、任意合约可调用） | 链上状态 + 曲线数学 | 散户 LP |
| 集中流动性 (v3) | 差（挪区间=发交易，又慢又贵） | 集中放大，需主动管理 | 极好 | 链上状态 + 曲线数学 | 散户/半专业 LP |
| Oracle 定价 AMM (Lifinity) | 好（= 预言机新鲜度，约几百 ms） | 大幅压缩，上限受制于 oracle | 好（链上合约） | oracle 签名 + 原子打包 | 协议自营 |
| RFQ | 好（每次询价现算现签） | 有效期窗口内不可撤（数秒） | 差（指名、单次、不可模拟） | 做市商签名 | 专业做市商 |
| Intent / UniswapX | 好（filler 接单时现算） | filler 自担执行风险 | 中（意图池开放，填单专业化） | 用户签名底线 + 合约强制 | filler（专业玩家） |
| PropAMM | 极好（毫秒级私有曲线更新） | 取决于链的排序保证（Part III） | 好（链上合约，聚合器可模拟*） | 链上状态 + **排序保证** 或 签名 | 专业做市商（不接受外部 LP） |

propAMM 的"聚合器可模拟"有一个星号：模拟可靠性取决于报价更新与 taker 成交之间的排序是否有保证——这正是 Part III 三条链的分水岭。

演化主线的一句话总结：**从 v2 到 v3 到 Lifinity 到 propAMM，是给"永不刷新报价的做市商"逐步装回方向盘的过程**——先允许他调保费（动态手续费），再帮他追回赃款（拍卖回收），然后证明可以不受伤（oracle 定价），最后把驾驶座整个让给专业司机（propAMM）。而 RFQ/intent 是平行的另一支：不解决"链上挂单"的新鲜度问题，直接用密码学签名绕开它——两支路线将在 Part III 之后的设计空间里重新汇合。
